# لعبة الذاكرة (Web Memory Game)

مشروع فرونت إند (Front-End) تفاعلي وممتع، يعتمد على الويب بشكل كامل وبدون استخدام أي مكتبات خارجية.

## التقنيات المستخدمة:
- **HTML5:** لبناء الهيكل البرمجي لشبكة الكروت.
- **CSS3:** لتصميم الواجهة، الألوان، والتأثيرات الحركية عند فتح الكروت.
- **JavaScript:** للتحكم بمنطق اللعبة (توزيع العناصر عشوائياً، حساب المحاولات، والتحقق من التطابق).

## ميزة المشروع:
لا يحتاج إلى أي تثبيت أو بيئة تشغيل، يمكن تشغيله مباشرة عبر أي متصفح إنترنت بمجرد فتح ملف `index.html`.
